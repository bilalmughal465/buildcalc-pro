Millimeters to Inches Converter

Convert millimeters to inches instantly with a simple, free calculator.

Formula

Inches = Millimeters × 0.0393701. Multiply the value in millimeters by 0.0393701 to get the value in inches.

How it works

Enter a value in millimeters. The calculator multiplies it by the conversion factor and shows the equivalent in inches, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many inches are in 1 millimeters?
One millimeters equals 0.0393701 inches. Multiply any value in millimeters by 0.0393701 to get inches.

Is this millimeters to inches conversion exact?
One inch equals exactly 25.4 millimeters, so the underlying conversion is exact before rounding.

When would I need a millimeters to inches conversion?
Any time a measurement, label, or instruction is given in millimeters and you need to work, compare, or record it in inches — for example while shopping, travelling, cooking, studying, or planning a project.
