Date Difference Calculator

Find how many days lie between two dates, using real calendar dates.

—

Formula

Days = absolute difference between the two calendar dates, counted in whole days. Leap years are handled automatically because real calendar dates are used.

How it works

Pick a start and an end date. The calculator subtracts the earlier date from the later one and reports whole days. The order does not matter: swapping the dates gives the same answer, since only the gap is measured.

FAQs

Does it count the start date, the end date, or neither?
It reports the gap between the dates, so 1 January to 2 January is 1 day. Add 1 if you need an inclusive count that includes both end dates.

Does it handle leap years?
Yes. Because it uses real calendar dates, 29 February is counted in leap years and skipped otherwise.

Can the end date be before the start date?
Yes. The result is the absolute gap, so the order of the two dates does not change the answer.
