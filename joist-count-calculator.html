Joist Count Calculator

Count floor or ceiling joists along a run at a given spacing, including both end joists.



—

Formula

Number of joists = (run length in centimetres divided by spacing in centimetres) plus one, rounded up, so both ends of the run have a joist.

How it works

Enter the length the joists must span across and their centre-to-centre spacing. The result includes a joist at each end. Joist size, grade and maximum span must still be checked against span tables or a professional design.

FAQs

What spacing is common?
Four hundred millimetres is common for many floors, but the correct spacing depends on joist size, load and local practice.

Does this count blocking or noggins?
No, only the joists themselves. Blocking, rim boards and fixings are extra.

Can I stretch spacing to save money?
Only if the design allows it. Wider spacing can cause bouncy floors or overload, so check first.
