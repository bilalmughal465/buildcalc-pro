Bird Cage Size (Rough) Calculator

Estimate minimum cage dimensions from a bird's wingspan, as a rough welfare guide.

—

Formula

Minimum cage width is about 1.5 times wingspan, depth about one wingspan, and height about twice wingspan.

How it works

Wingspan sets the scale so the bird can spread its wings and move. These are minimums, not ideals, and long-tailed species need extra height while active species need extra width.

FAQs

Is bigger always better?
Generally yes, as long as bar spacing stays safe for the species.

Does height matter more than width?
Width matters most for flight; height matters for long tails and climbing.

What about out-of-cage time?
Daily supervised time outside helps, but does not excuse a tiny cage.

General information only, not veterinary advice.
