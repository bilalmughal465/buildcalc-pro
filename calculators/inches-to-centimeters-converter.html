Inches to Centimeters Converter

Convert inches to centimeters instantly with a simple, free calculator.

Formula

Centimeters = Inches × 2.54. Multiply the value in inches by 2.54 to get the value in centimeters.

How it works

Enter a value in inches. The calculator multiplies it by the conversion factor and shows the equivalent in centimeters, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many centimeters are in 1 inches?
One inches equals 2.54 centimeters. Multiply any value in inches by 2.54 to get centimeters.

Is this inches to centimeters conversion exact?
One inch is defined as exactly 2.54 centimeters, so this conversion is exact before rounding.

When would I need a inches to centimeters conversion?
Any time a measurement, label, or instruction is given in inches and you need to work, compare, or record it in centimeters — for example while shopping, travelling, cooking, studying, or planning a project.
