Convert kWh to joules instantly with a simple, free calculator.

Formula

Joules = Kwh × 3.6e+06. Multiply the value in kWh by 3.6e+06 to get the value in joules.

How it works

Enter a value in kWh. The calculator multiplies it by the conversion factor and shows the equivalent in joules, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many joules are in 1 kWh?
One kWh equals 3.6e+06 joules. Multiply any value in kWh by 3.6e+06 to get joules.

Is this kWh to joules conversion exact?
One watt is one joule per second, so one kilowatt-hour is 1,000 watts for 3,600 seconds — exactly 3,600,000 joules.

When would I need a kWh to joules conversion?
Any time a measurement, label, or instruction is given in kWh and you need to work, compare, or record it in joules — for example while shopping, travelling, cooking, studying, or planning a project.
