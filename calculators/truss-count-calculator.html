Truss Count Calculator

Count roof trusses along a building length at a given spacing, including both end trusses.



—

Formula

Number of trusses = (building length divided by truss spacing) plus one, rounded up, so both ends have a truss.

How it works

Enter the building length the trusses run along and their centre-to-centre spacing. The count includes an end truss at each side. Truss design, bracing and connections must come from the truss manufacturer or a structural design, not from this count.

FAQs

What spacing is typical?
Six hundred millimetres is common in many houses, but the design may specify something else.

Does this include gable trusses?
End trusses are included in the count, but special gable or dropped trusses must be confirmed with the supplier.

Can I change spacing to use fewer trusses?
Only if the truss design allows it. Spacing affects loads on each truss and on the roof covering.
