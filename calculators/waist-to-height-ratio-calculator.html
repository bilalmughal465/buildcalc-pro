Waist-to-Height Ratio Calculator

Divide waist by height; keeping the result under 0.5 is a common rough guide.

—

Formula

Waist-to-height ratio equals waist circumference divided by height, in the same units.

How it works

Both measurements in centimetres are divided, so the result has no units. Because height is included, the same waist means something different for a tall and a short person.

FAQs

Why 0.5?
It is a simple public-health guide: waist under half your height.

Is it exact?
No, but it is easy to check and less fooled by muscle than BMI alone.

Should children use it?
Guides differ by age, so this adult guide should not be applied to children.
