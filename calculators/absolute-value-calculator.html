Absolute Value Calculator

Find the absolute value of a number, its distance from zero with the sign removed.

—

Formula

Absolute value of x is x if x is positive or zero, and −x if x is negative.

How it works

Enter any number. The calculator drops a minus sign if there is one. For example, the absolute value of −7 is 7.

FAQs

What does the Absolute Value do?
It takes the values you enter and works out the absolute value for you, showing the result straight away.

What should I enter?
Enter ordinary numbers in the boxes above. If a value does not make sense for this calculation, the page will ask you to check it instead of showing a wrong answer.

Can I use the result for homework or everyday maths?
Yes. It is a general-purpose maths helper; for exam or professional work, still check the steps against your own working.
