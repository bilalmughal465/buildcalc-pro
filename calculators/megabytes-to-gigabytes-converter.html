Formula

Gb = Mb × 0.000976562. Multiply the value in MB by 0.000976562 to get the value in GB.

How it works

Enter a value in MB. The calculator multiplies it by the conversion factor and shows the equivalent in GB, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many GB are in 1 MB?
One MB equals 0.000976562 GB. Multiply any value in MB by 0.000976562 to get GB.

Is this MB to GB conversion exact?
This calculator uses the binary convention where 1 GB equals 1,024 MB. Some storage makers use 1,000 MB per GB, which gives a slightly larger GB figure.

When would I need a MB to GB conversion?
Any time a measurement, label, or instruction is given in MB and you need to work, compare, or record it in GB — for example while shopping, travelling, cooking, studying, or planning a project.
