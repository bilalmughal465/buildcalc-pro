Formula

Tb = Gb × 0.000976562. Multiply the value in GB by 0.000976562 to get the value in TB.

How it works

Enter a value in GB. The calculator multiplies it by the conversion factor and shows the equivalent in TB, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many TB are in 1 GB?
One GB equals 0.000976562 TB. Multiply any value in GB by 0.000976562 to get TB.

Is this GB to TB conversion exact?
This uses the binary convention where 1 TB equals 1,024 GB. Decimal labelling by some makers uses 1,000 GB per TB instead.

When would I need a GB to TB conversion?
Any time a measurement, label, or instruction is given in GB and you need to work, compare, or record it in TB — for example while shopping, travelling, cooking, studying, or planning a project.
