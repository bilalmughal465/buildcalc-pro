Portion Cost Calculator

Buying in bulk only saves money if the per-portion cost actually drops. Divide the bulk price by weight, then multiply by your portion.

—

Formula

Portion cost = (bulk price / bulk weight) x portion weight.

How it works

This is the same math shops use for unit pricing, applied to your own portions. It makes bulk-vs-small-pack comparisons honest.

Remember waste: if part of the bulk pack spoils before you use it, the true portion cost rises. Buy bulk only for foods you finish.

FAQs

Why is bulk sometimes more expensive?
Because a large pack can hide a higher per-kilo price behind a bigger total. Always compare per kilo, not per pack.

Should I count trim and waste?
If you trim a lot, yes — base the portion on the usable weight, not the pack weight.

What units work here?
Any consistent weight unit works, as long as bulk weight and portion weight use the same one.
