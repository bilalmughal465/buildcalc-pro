Outlet Count Rough Calculator

Estimate a rough number of wall outlets from total wall length and spacing between outlets.



—

Formula

Rough outlet count = total wall length divided by spacing between outlets, rounded up.

How it works

Add up the usable wall length in the room and divide by the spacing you plan between outlets. The count is a planning guide for layouts and quotes. Real outlet placement must follow local electrical codes and the room's actual use, not spacing alone.

FAQs

Is spacing the only rule?
No. Codes also set rules for kitchens, bathrooms and special locations, and some walls need an outlet regardless of spacing.

Should doors and windows break the run?
Yes, measure usable wall sections separately in practice, since outlets cannot sit inside a doorway.

Who should install outlets?
A qualified electrician. This calculator plans counts only and is not an electrical design.
