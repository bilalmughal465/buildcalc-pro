Pounds to Kilograms Converter

Convert pounds to kilograms instantly with a simple, free calculator.

—

Formula

Kilograms = Pounds × 0.453592. Multiply the value in pounds by 0.453592 to get the value in kilograms.

How it works

Enter a value in pounds. The calculator multiplies it by the conversion factor and shows the equivalent in kilograms, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many kilograms are in 1 pounds?
One pounds equals 0.453592 kilograms. Multiply any value in pounds by 0.453592 to get kilograms.

Is this pounds to kilograms conversion exact?
One pound is defined as exactly 0.45359237 kilograms, so the conversion is exact before rounding.

When would I need a pounds to kilograms conversion?
Any time a measurement, label, or instruction is given in pounds and you need to work, compare, or record it in kilograms — for example while shopping, travelling, cooking, studying, or planning a project.
