Kilometers to Miles Converter

Convert kilometers to miles instantly with a simple, free calculator.

—

Formula

Miles = Kilometers × 0.621371. Multiply the value in kilometers by 0.621371 to get the value in miles.

How it works

Enter a value in kilometers. The calculator multiplies it by the conversion factor and shows the equivalent in miles, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many miles are in 1 kilometers?
One kilometers equals 0.621371 miles. Multiply any value in kilometers by 0.621371 to get miles.

Is this kilometers to miles conversion exact?
One mile is defined as 1.609344 kilometers, so this conversion is exact before rounding to a sensible number of decimals.

When would I need a kilometers to miles conversion?
Any time a measurement, label, or instruction is given in kilometers and you need to work, compare, or record it in miles — for example while shopping, travelling, cooking, studying, or planning a project.
