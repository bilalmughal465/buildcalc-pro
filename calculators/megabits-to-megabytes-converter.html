Megabits per Second to Megabytes per Second Converter

Convert Mbps to MB/s instantly with a simple, free calculator.

Formula

Mb/s = Mbps × 0.125. Multiply the value in Mbps by 0.125 to get the value in MB/s.

How it works

Enter a value in Mbps. The calculator multiplies it by the conversion factor and shows the equivalent in MB/s, rounded to at most four decimal places so long decimals stay readable. Negative values are converted the same way, since the factor applies in both directions of the scale.

FAQs

How many MB/s are in 1 Mbps?
One Mbps equals 0.125 MB/s. Multiply any value in Mbps by 0.125 to get MB/s.

Is this Mbps to MB/s conversion exact?
There are 8 bits in a byte, so divide megabits per second by 8 to get megabytes per second. Internet speeds are usually quoted in bits, file sizes in bytes.

When would I need a Mbps to MB/s conversion?
Any time a measurement, label, or instruction is given in Mbps and you need to work, compare, or record it in MB/s — for example while shopping, travelling, cooking, studying, or planning a project.
