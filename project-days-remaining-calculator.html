Project Days Remaining Calculator

Count working-day style calendar days left until a project deadline.

—

Formula

Days remaining = deadline date minus today's date, in whole calendar days.

How it works

Enter the project deadline and today's date. The calculator reports whole days left, which is the simplest way to track a deadline; if you need working days only, use the working-days calculator for the same range.

FAQs

Are weekends included?
Yes. This counts calendar days. Use the working-days calculator if only weekdays should count.

Is today counted?
No. Today is day 0, so a deadline tomorrow is 1 day away.

What if the deadline has passed?
The calculator reports how many days ago it passed.
