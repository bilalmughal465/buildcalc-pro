Internet Download Time Calculator

File sizes are usually in megabytes while speeds are in megabits per second — the factor of 8 between them is the key step.

—

Formula

Time (seconds) = file size (MB) x 8 / speed (Mbps).

How it works

The 8 comes from bits versus bytes: 1 byte is 8 bits, so a 50 Mbps connection moves about 6.25 megabytes per second, not 50.

Real downloads run slower than the headline speed because of network overhead, server limits and other devices sharing the connection.

FAQs

Why is my download slower than my plan speed?
Overhead, server speed, Wi-Fi signal and other users all reduce the speed you actually get.

What is the difference between MB and Mb?
MB means megabytes, Mb means megabits. Internet speeds are advertised in megabits, so downloads need the divide-by-8 step.

Does file size in GB work here?
Convert first: 1 GB is 1,000 MB for this estimate (or 1,024 MB strictly), then enter the MB figure.
