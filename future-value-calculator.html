Future Value Calculator

Calculate what a present amount will be worth after growing at a set rate.

—

Formula

Future value equals present value times one plus the rate, raised to the number of years.

How it works

This is the core growth formula behind savings and investing. It assumes a steady rate every year, which real investments rarely deliver, so treat the result as a scenario, not a promise.

FAQs

Does it include new deposits?
No — use the compound interest with contributions calculator for regular deposits.

Why do small rate changes matter so much?
Compounding over many years magnifies even a 1% difference.

Is inflation included?
No, this is a nominal value before inflation.

Are these figures financial advice?
No — they are estimates for planning only, not financial advice. Check with a qualified adviser for decisions involving large sums.
